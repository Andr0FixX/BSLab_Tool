## 🚀 About Me

I am a passionate **Systems & Firmware Software Engineer** specializing in low-level hardware communication, USB protocol implementation, kernel drivers, and Android firmware architecture. I design high-throughput desktop applications that interface directly with system-on-chip (SoC) bootloaders and emergency download protocols.

* 🛠️ **Author & Lead Architect** of [**BS Lab Tool PRO**](https://github.com/Andr0FixX/BSLab_Tool) — an enterprise multi-chipset Android servicing and partition forensics suite powered by pure **Native C++20**.
* 🔬 Deep technical expertise in **SoC architectures**: MediaTek (Dimensity/Helio), Qualcomm Snapdragon, Samsung Exynos, Unisoc, and HiSilicon Kirin.
* ⚡ Obsessed with zero-overhead native performance, microsecond protocol timings, and eliminating slow runtime layers.
* 🔍 Actively researching embedded security, bootloader state-machines, cryptographic handshakes, and eMMC/UFS partition forensics.
