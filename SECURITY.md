# Security Policy

## 🔒 Supported Versions

We actively support and provide security patches for the following versions of BS Lab Tool PRO:

| Version | Supported          | Status |
| ------- | ------------------ | ------ |
| 2.5.x   | :white_check_mark: | Active (Current Native Enterprise Release) |
| 2.0.x   | :x:                | Deprecated |
| < 2.0   | :x:                | End of Life |

---

## 🚨 Reporting a Vulnerability

The BS Lab Tool team takes the security and integrity of low-level device communication seriously.

If you discover a security vulnerability or exploit risk (such as memory corruption, buffer overflows in USB parsing, or cryptographic flaws), please **do not open a public issue**.

Instead, report it responsibly via:
* **Email**: `security@bslabtool.com` or private developer message
* **GitHub Security Advisory**: Open a private advisory under the repository's **Security** tab.

Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept (PoC) code/sample file.
3. Affected hardware architecture or protocol engine.

We acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
